# Example output

![Mars offlane thumbnail](mars-thumbnail.jpg)

Generated with:

```bash
python -m ytupload thumbnail --hero "Mars" \
  --hero-image <official Mars promo art> \
  --badges "blink,mars_arena_of_blood"
```

1280x720, 160 KB. The layout, vignette and badge rings are produced by
`ytupload`; the accent colour is sampled from the artwork itself, so each hero
themes its own thumbnail with nothing hardcoded.
