ytupload

A command-line tool for uploading Dota 2 match recordings to YouTube.

ytupload is an open-source personal tool. It runs on its owner's own computer and uploads that person's own gameplay recordings to their own YouTube channel. It is not a hosted service and has no server component.

What it does

  • Uploads large video files resumably, so a dropped connection does not restart the transfer.
  • Cuts a full match down to a highlight edit of a target length.
  • Builds thumbnails from official hero artwork.
  • Adds uploads to a playlist and sets a custom thumbnail.

Source

The complete source code is public at github.com/WangCHEN9/youtuber_uploader, released under the MIT licence.
